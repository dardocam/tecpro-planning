# Proyecto Integrador Final

## ¿Para qué aprender a programar cuando existe la IA?

Las herramientas de Inteligencia Artificial pueden generar código, diseñar interfaces y resolver muchos problemas de programación.

Entonces aparece una pregunta importante:

> **Si una IA puede programar, ¿para qué necesitamos aprender a programar nosotros?**

Este proyecto busca responder esa pregunta mediante la práctica.

---

## El desafío

A partir de su propio proyecto web con base de datos, deberán desarrollar una **aplicación móvil complementaria** utilizando React Native + Expo + JavaScript.

La aplicación deberá comunicarse con la API de su proyecto y utilizar información real de la base de datos.


Deberá incorporar **al menos una funcionalidad pensada específicamente para dispositivos móviles**.

Algunos ejemplos:

* consulta rápida de información;
* carga de datos desde el teléfono;
* registro de actividades;
* notificaciones;
* ubicación;
* captura de fotografías;
* escaneo de códigos;
* seguimiento de información;
* panel de control;
* actualización de estados;
* otra funcionalidad justificada por el proyecto.

---

# Trabajo que necesariamente debe realizar el estudiante

Estas partes serán consideradas fundamentales y deberán ser producidas, comprendidas y defendidas por los integrantes del grupo.

### A. Definición del problema

El grupo deberá explicar:

* qué problema pretende resolver;
* quién utilizará la aplicación;
* qué necesidad concreta atiende;
* por qué resulta útil incorporar una aplicación móvil.

---

### B. Diseño de la solución

Antes de programar deberán definir:

* funcionalidades;
* flujo de navegación;
* pantallas;
* datos necesarios;
* comunicación con la API;
* operaciones que podrá realizar el usuario.

El diseño deberá estar justificado por el proyecto.

---

### C. Integración

El grupo deberá ser capaz de explicar y demostrar:

```text
Aplicación móvil
       ↓
      API
       ↓
     Lógica
       ↓
   Base de datos
```

Deberán identificar claramente qué parte corresponde a cada componente.
---
Pero el objetivo principal **no es producir código**.

El objetivo es demostrar que ustedes pueden:

**comprender un problema → tomar decisiones → utilizar IA como herramienta → comprobar sus resultados → detectar errores → modificar la solución → explicar lo realizado.**

---

## ¿Qué puede hacer la IA?

Pueden utilizar IA para:

* generar código;
* explicar conceptos;
* buscar errores;
* proponer soluciones;
* consultar documentación;
* sugerir alternativas.

## ¿Qué debe hacer el ser humano?

Hay cuestiones que no deben delegarse:

**Definir qué problema quieren resolver.**

**Decidir qué debe hacer la aplicación.**

**Diseñar la solución.**

**Evaluar si una propuesta de IA realmente sirve.**

**Comprobar que el código funciona y es seguro.**

**Detectar errores y corregirlos.**

**Comprender el código utilizado.**

**Poder cambiarlo cuando una situación lo requiera.**

**Explicar y defender las decisiones tomadas.**

---

## Idea central

> **La IA puede escribir código.
> El profesional debe saber qué código necesita, por qué lo necesita y cómo saber si está bien.**

Por eso, durante la evaluación no alcanzará con mostrar una aplicación funcionando.

Cada integrante deberá demostrar que **comprende y puede modificar su propia solución**, aunque haya utilizado Inteligencia Artificial para desarrollarla.

---

# Defensa individual

La evaluación tendrá una instancia de **defensa individual**.

Cada integrante deberá explicar una parte del proyecto.

Además, el docente podrá solicitar una modificación sencilla sobre el proyecto terminado.

Por ejemplo:

> agregar una validación;

> modificar una consulta;

> cambiar el comportamiento de un botón;

> incorporar un dato;

> modificar una condición;

> explicar y corregir un error.

### Importante

**No será suficiente decir “eso lo hizo la IA”.**

El estudiante deberá demostrar que comprende la solución presentada.

---

# Producto final

Cada grupo deberá entregar:

1. Aplicación móvil funcionando.
2. Código fuente.
3. API utilizada.
4. Base de datos del proyecto.
5. Documentación técnica.
6. Registro de utilización de IA.
7. Evidencias de pruebas.
8. Presentación y defensa individual.

---

# Criterio fundamental de evaluación

El proyecto no se evaluará únicamente por:

> **“¿La aplicación funciona?”**

También se evaluará:

> **“¿Sus autores pueden explicar cómo funciona, por qué fue construida de esa manera y modificarla cuando sea necesario?”**

Una aplicación técnicamente correcta pero que sus autores no pueden comprender o modificar **no demuestra el aprendizaje esperado**.

---
## Pregunta central del proyecto

Durante todo el desarrollo deberán poder responder:

> **¿Podemos demostrar que nosotros construimos y comprendemos esta solución, aunque hayamos utilizado IA para ayudarnos?**
