# Temario de Saberes Previos para el Desarrollo de Aplicaciones Móviles con React Native

**Nivel:** 7.º año – Tecnicatura en Programación
**Propósito:** Evaluación diagnóstica de saberes previos
**Área:** Desarrollo de Software
**Tecnología objetivo:** React Native

---

## 1. Propósito

El presente temario establece los **saberes previos que se espera que un estudiante haya adquirido durante su trayectoria en la Tecnicatura en Programación** antes de abordar el desarrollo de aplicaciones móviles con React Native.

La evaluación de estos contenidos tiene carácter **diagnóstico** y busca determinar si los estudiantes cuentan con una base conceptual suficiente para abordar posteriormente, tanto desde el punto de vista teórico como práctico, el desarrollo de una aplicación móvil.

**React y React Native no forman parte de esta evaluación**, ya que constituyen contenidos propios del año en curso.

El objetivo no es evaluar conocimientos específicos de una tecnología móvil, sino comprobar la existencia de las **competencias previas necesarias para aprender y utilizar dicha tecnología**.

---

# 2. Competencias previas

La evaluación se estructura en seis competencias:

1. Programación y resolución de problemas.
2. JavaScript.
3. Datos y estructuras de información.
4. Comunicación entre aplicaciones y servidores.
5. Persistencia y bases de datos.
6. Herramientas y prácticas básicas de desarrollo.

---

# 3. Competencia 1 — Programación y resolución de problemas

## Saberes

El estudiante deberá comprender los fundamentos de la programación y utilizarlos para analizar y resolver problemas sencillos.

### Contenidos

* Algoritmos.
* Variables y constantes.
* Tipos de datos.
* Operadores.
* Expresiones.
* Estructuras condicionales.
* Estructuras repetitivas.
* Funciones.
* Parámetros.
* Valores de retorno.
* Modularización.
* Manejo básico de errores.
* Resolución de problemas mediante algoritmos.

### Se espera que el estudiante pueda

* interpretar un algoritmo;
* seguir la ejecución de un programa;
* identificar entradas, procesos y salidas;
* determinar el resultado de un fragmento de código;
* reconocer errores lógicos sencillos;
* seleccionar una estructura de control adecuada para resolver un problema;
* comprender el funcionamiento de una función.

El estudiante deberá comprender los principios básicos de comunicación entre una aplicación cliente y un servidor.

### Contenidos

* Cliente y servidor.
* Comunicación mediante redes.
* HTTP.
* URL.
* Endpoint.
* Request.
* Response.
* Métodos HTTP:

  * GET
  * POST

  * PATCH
  * DELETE

* API REST.

* Códigos de estado HTTP básicos.

### Se espera que el estudiante pueda

# 10. Perfil esperado al finalizar la evaluación

Se considera que un estudiante posee una **base adecuada para abordar el aprendizaje de React Native** cuando demuestra que puede:

1. Resolver problemas utilizando conceptos fundamentales de programación.
2. Interpretar y analizar código JavaScript.
3. Trabajar con arrays, objetos y estructuras de datos.
4. Comprender y manipular información representada en JSON.
5. Comprender la comunicación entre cliente, API, backend y base de datos.
6. Comprender los principales métodos HTTP.
7. Comprender el concepto de persistencia.
8. Interpretar estructuras básicas de bases de datos y operaciones CRUD.
9. Comprender el uso de dependencias y bibliotecas.
10. Interpretar errores básicos de programación.
11. Comprender los conceptos fundamentales de control de versiones con Git.

# 11. Relación con las evaluaciones posteriores

El diagnóstico se desarrollará en dos instancias complementarias.

### Primera instancia — Evaluación teórica

Busca determinar si el estudiante **comprende los conceptos y puede razonar sobre ellos**.

```text
Saberes previos
       ↓
Evaluación teórica
       ↓
Diagnóstico conceptual
```

### Segunda instancia — Evaluación práctica

Busca determinar si el estudiante **puede utilizar esos conocimientos para resolver problemas concretos**.

```text
Saberes previos
       ↓
Evaluación práctica
       ↓
Diagnóstico de desempeño
```

Ambas instancias permitirán determinar el grado de preparación del grupo antes de avanzar hacia el desarrollo de aplicaciones móviles.

---

# 12. Propósito final

El diagnóstico no pretende determinar únicamente si un estudiante "sabe o no sabe" determinados contenidos.

Su finalidad principal es identificar si existe una **base común de conocimientos que permita comenzar el aprendizaje de React Native en condiciones adecuadas** y detectar aquellos saberes que requieren refuerzo antes de abordar el proyecto móvil.

La secuencia formativa será:

**Saberes previos → Diagnóstico teórico → Diagnóstico práctico → React → React Native → Proyecto de aplicación móvil**
